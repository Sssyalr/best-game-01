FERROX-9 is a compact first-person shooter set in a derelict orbital foundry: restart three fusion cores while Warden Orbs and Scrap Scuttlers hunt you, then reach the extraction pad to get out alive. Built with Three.js (vendored), procedural textures and synthesized Web Audio sound — no network, no assets to download.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Click to capture the mouse, WASD to move, click to fire, R to reload, hold E to restart a core.
